# Eurozuca Admin Painel

Plugin WordPress completo para personalizar o site eurozuca.com com painel de administração intuitivo.

## 🎯 Funcionalidades

- ✅ **Cores Personalizáveis** - 7 cores configuráveis (tricolores + auxiliares)
- ✅ **Fontes do Google** - Escolha entre 8+ fontes principais e de títulos
- ✅ **6 Templates Prontos** - Padrão, Moderno, Dark, Minimalista, Oceano, Pôr do Sol
- ✅ **Conteúdo Editável** - Todos os textos, títulos e descrições
- ✅ **SEO Integrado** - Meta tags, Open Graph, keywords
- ✅ **Bordas Tricolores** - Efeito visual verde-dourado-azul em todos os elementos
- ✅ **Exportar/Importar** - Salve e compartilhe configurações
- ✅ **Download HTML** - Gere arquivo HTML standalone

## 📦 Instalação

### Método 1: Upload via WordPress (Recomendado)

1. Baixe o arquivo `eurozuca-admin.zip`
2. No WordPress, vá em **Plugins → Adicionar Novo → Enviar Plugin**
3. Selecione o arquivo ZIP e clique em **Instalar Agora**
4. Ative o plugin

### Método 2: FTP

1. Descompacte o arquivo `eurozuca-admin.zip`
2. Envie a pasta `eurozuca-admin` para `/wp-content/plugins/`
3. No WordPress, vá em **Plugins** e ative "Eurozuca Admin Painel"

## 🚀 Como Usar

### 1. Acessar o Painel

Após ativar o plugin, vá em **Eurozuca → Painel** no menu do WordPress.

### 2. Personalizar

Navegue pelas abas:
- **Dashboard** - Visão geral e acesso rápido
- **Cores** - Altere todas as cores do site
- **Fontes** - Escolha fontes e tamanhos
- **Templates** - Selecione um template pré-definido
- **Conteúdo** - Edite todos os textos
- **SEO** - Configure meta tags
- **Exportar** - Baixe o HTML ou exporte configurações

### 3. Salvar

Clique em **"Salvar Alterações"** no topo da página.

### 4. Exibir no Site

Use um dos shortcodes em qualquer página do Elementor:

```
[eurozuca_site]
```

Exibe o site completo com todas as personalizações.

## 📝 Shortcodes Disponíveis

| Shortcode | Descrição |
|-----------|-----------|
| `[eurozuca_site]` | Exibe o site completo |
| `[eurozuca_painel]` | Exibe o painel de admin (apenas logados) |

## ⚙️ Configurações

### Cores Editáveis

- Verde Principal
- Dourado/Amarelo
- Azul
- Fundo Principal
- Fundo Secundário
- Cor dos Cards
- Texto Principal
- Texto Secundário
- Texto Muted

### Fontes Disponíveis

**Principais:** Inter, Roboto, Open Sans, Lato, Montserrat, Poppins, Nunito, Source Sans Pro

**Títulos:** Space Grotesk, Inter, Roboto, Montserrat, Poppins, Oswald, Raleway, Bebas Neue

### Layout

- Bordas arredondadas (0-50px)
- Espaçamento entre cards
- Sombra dos cards (nenhuma, pequena, média, grande)
- Animações (ligar/desligar)

## 💾 Backup e Exportação

### Exportar Configuração

1. Vá na aba **Exportar**
2. Clique em **"Exportar Configuração (JSON)"**
3. Salve o arquivo em local seguro

### Importar Configuração

1. Vá na aba **Exportar**
2. Selecione o arquivo JSON
3. As configurações serão aplicadas automaticamente

### Download HTML

1. Vá na aba **Exportar**
2. Clique em **"Baixar index.html"**
3. Use o arquivo em qualquer servidor

## 🔧 Requisitos

- WordPress 5.0+
- PHP 7.4+
- Elementor (opcional, para usar shortcodes)

## 🆘 Suporte

Em caso de dúvidas ou problemas:

1. Verifique se o plugin está ativado
2. Limpe o cache do navegador
3. Desative outros plugins temporariamente para testar conflitos
